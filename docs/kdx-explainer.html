How files work here

[DIR] is a folder, [FILE] is a file. A [DROP] box is a folder people can write into but no one can list: the write-only vault for submissions.

An [→] alias is a soft pointer. The same bytes appear in two places without duplicating on disk, and the target's own class gate still applies: you can't bypass a stricter folder by aliasing it into a permissive one.

Access is a class check against the folder, and the folder is the whole fence. No cloud, no API, no third party. The bytes live on your disk.

Get Started

+
−

Run the server

$cargo install --git https://github.com/iamkhayyam/kdx-hotline kdxd

Rust binary, SQLite under the hood, TLS cert self-generated on first run. One port, one process, your box.

Get the client

$cargo install --git https://github.com/iamkhayyam/kdx-hotline kdx-client

Tauri desktop app for macOS, Linux, Windows. Trust-on-first-use certificate pinning. Also runs in a browser against the dist bundle.

Read the source

$git clone https://github.com/iamkhayyam/kdx-hotline

Everything is on GitHub. Rust workspace, ~230 tests, clippy clean. Protocol is binary and documented in the handoff docs.
