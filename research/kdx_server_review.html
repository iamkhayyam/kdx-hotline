KDX is like a swiss army knife for internet and intranet communications. KDX is a powerful multi-OS "BBS"-style (Bulletin Board System) encrypted internet communications system that provides voice chat (Internet Telephone), text chat, messaging, news, file and folder transfer, remote access, trackers and more.

It uses strong encryption to protect your communications for security and privacy. It is very useful for groups that need to collaborate on a project via the Internet. It is also very useful for remote administration of a computer. KDX uses a client/server architecture (NOT peer-to-peer).

While KDX works very well over the Internet, it also works very well on a LAN (local area network). KDX does not require an Internet connection, and is thus suitable for use on an internal company LAN, and for home or small business networking.
