 Hotline Server (software) 
 From Higher Intellect Vintage Wiki 
 The Hotline server application receives connections from the Hotline Client (software) and may also list on trackers running the Hotline Tracker (software) . A default installation of the server software features a guest account for general public access and a full administration account allowing you to manipulate files, create/modify user accounts, etc.
 The official Hotline server software was released under Macintosh and Windows, though the protocol was unofficially available on other operating systems such as *nix variants.
 The Hotline Server enables you to easily and safely run your own personal server on almost any Macintosh and PC running Windows 95 and Windows NT. The Hotline Server is a powerful yet easy to use tool for anyone who needs a way to stay in contact and share files, information and ideas. To allow others to easily find and connect to your server, you can register your Server with a Hotline Tracker, which acts like an Internet Phonebook. Once registered, your server becomes available for anyone to look-up and connect to. There exists the concern that some users might not be comfortable with the idea of allowing other users, especially on the Internet, to connect to and access their own personal computer. However, security was a key consideration when developing Hotline, and the Company has built the server to incorporate several levels of security, providing reliable protection for your files and your computer.
 Summary of Key Features: 
 Can turn any Mac or PC into a server 
 Capable of hosting chat, peer groups, news and messaging 
 Chat - including private chat 
 Cross-platform - Macs and PCs can connect to a Hotline Server regardless of the platform and chat, post news and transfer files 
 Hotline Server can be easily administered using the Hotline Client 
 Low RAM requirements 
 Hotline protocols maximize net work bandwidth and are optimized for both high-speed connections as well as for the average user on a 28.8 kbps modem.
